# HUD 四种布局方向讨论

## 原始需求

用户希望把 HUD 现有的横向、竖向两种显示方向扩展为四种，以三色灯组所在的一端命名：横向左、横向右、竖向上、竖向下。标题始终位于图标与灯组之间。

## 问答记录

1. 问：切到横向左或竖向上时，三色灯组内部顺序是否仍保持红→黄→绿，只移动整组？答：确认，整组保持不变。
2. 问：四种布局是否分别记住位置，新布局首次沿用同方向现有位置？答：确认。
3. 问：背景透明度达到 90% 时，图标隐藏并缩短 40 点，是否始终固定灯组所在的一端？答：确定；并补充标题始终在中间。
4. 问：竖向上时标题文字是否仍保持现有从上到下的阅读方向，不倒转？答：确认。
5. 问：设置中是否将“显示方向”改成“HUD 布局”的四项下拉选择；旧横向映射横向右、旧竖向映射竖向下，首次安装默认横向右？答：确认。
6. 问：布局切换是否立即更新排列和各自保存的位置，正在拖动时取消该次手势、不保存中途位置？答：确认。
7. 问：“标题在中间”是否指标题区域在图标与灯组之间，横向文字继续靠左？答：确认。用户进一步明确：标题区域的排列位置居中，不要求区域内文字居中；横向文字始终左对齐，竖向文字始终靠上。

## 最终共识

| 布局名称 | 从左到右／从上到下的区域顺序 |
| --- | --- |
| 横向左 | 灯组 → 标题 → 图标 |
| 横向右 | 图标 → 标题 → 灯组（现有横向） |
| 竖向上 | 灯组 → 标题 → 图标 |
| 竖向下 | 图标 → 标题 → 灯组（现有竖向） |

- 名称中的左右上下只表示灯组在 HUD 内的位置，不要求 HUD 自动贴合屏幕的左／右／上／下边缘。
- 灯组内部从左到右或从上到下仍是红→黄→绿；文字不反转。横向标题文字靠左，竖向标题文字靠上。
- 四种布局独立记忆位置。新布局首次使用对应方向的旧位置，后续互不覆盖。
- 高透明度隐藏图标时，窗口从图标一端缩短，灯组一端不动；标题区域保留原尺寸。
- 切换布局立即完成。正在拖动时取消手势，不保存半途位置。旧设置及旧位置数据保留兼容。
- 开发规格见 `docs/plan/2026-09-28-hud-four-layout-directions.md`，等待用户批准后编码。
