# HUD 标题颜色切换讨论

## 原始需求

用户发现背景透明度超过 50% 后，黑色标题移到深色背景上会看不清，希望在设置中手动选择白色或黑色标题。

## 逐项问答

1. 问：是否使用黑／白两项，默认黑色，切换立即生效、保存并在重启后恢复？答：确认；控件采用 Switch，左侧黑色、右侧白色。
2. 问：颜色只改变 HUD 标题，还是连左侧图标一起改变？答：只调整标题。
3. 问：颜色是否始终手动控制，不随透明度、系统深浅模式或显示器背景自动变化？答：用户询问能否读取 HUD 所在区域的背景颜色并自动选择。
4. 答复：读取当前下层画面需要屏幕录制权限及区域采样；读取壁纸无法反映覆盖其上的窗口。自动模式还要处理频繁变化和 HUD 自身被采样的问题。问是否纳入本版？答：本版先手动选择，后续再考虑自动实现。
5. 问：Switch 是否放在“背景透明度”滑块旁，左侧黑色、右侧白色，默认黑色，立即预览并保存？答：确认。
6. 问：颜色是否覆盖横向与纵向会话标题、无会话时的“Traceflow”占位标题和纵向省略号，同时保持图标、状态灯、设置页文字不变？答：确认。

## 代码现状与最终共识

- 横向标题由 SwiftUI `Text` 绘制，目前未指定标题颜色，继承环境文字色。
- 纵向标题由 `VerticalMixedTitleView` 的 AppKit/Core Text 视图绘制，目前文字与省略号使用 `NSColor.labelColor`。
- 本版新增手动黑／白 Switch，默认黑色；立即生效、持久化、重启恢复；独立于透明度、系统深浅模式和背景颜色。
- 标题范围包含会话标题、占位标题、纵向省略号。图标、状态灯和其他 UI 颜色不变。
- 自动读取屏幕背景不在本版范围；未来可单独设计权限、采样和防闪烁规则。
- 开发规格见 `docs/plan/2026-09-28-hud-title-color-switch.md`，须经用户批准后实施。
