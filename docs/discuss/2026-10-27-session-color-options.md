# 会话颜色候选讨论

## 原始需求

会话颜色浮层不希望所有会话显示相同的预设颜色；讨论同一会话每次打开时颜色是否应变化。

## 问答与确认

1. 同一会话的候选颜色每次打开是否变化？答：保持固定；不同会话的候选有所区别。
2. 其他会话使用颜色变化时，是否调整当前会话候选以避让？答：优先保持固定，不随其他会话变化；不同会话可能出现相同候选颜色。
3. 色位数量和当前颜色如何展示？答：保留六个色位；当前颜色不在固定候选中时，用第一个色位显示当前颜色，其余五个显示固定候选。

## 最终共识

每个会话依据自身稳定标识生成固定候选，重启后仍一致，不依赖其他会话的状态。浮层始终展示当前颜色并标记选中，保留末尾“自定义”入口。当前颜色本身发生变化时，按上述规则更新选中项或第一色位。
